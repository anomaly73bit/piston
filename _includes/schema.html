{%- comment -%} Schema della disposizione dei cilindri. In alto: sezione trasversale con l'angolo reale tra le bancate. In basso: vista dall'alto con il numero di cilindri per bancata. Parametri: arch (architettura), n (cilindri), angolo (gradi tra le bancate, per V e W) {%- endcomment -%} {%- assign arch = include.arch | append: "" -%} {%- assign n = include.n | plus: 0 -%} {%- assign prima = arch | slice: 0 -%} {%- if prima == "V" -%} {%- assign mezzo = include.angolo | divided_by: 2.0 -%} {%- assign angoli = "" | append: mezzo | prepend: "-" | append: "," | append: mezzo -%} {%- assign righe = 2 -%} {%- elsif prima == "W" -%} {%- assign angoli = "-52.5,-37.5,37.5,52.5" -%} {%- assign righe = 4 -%} {%- elsif arch contains "Boxer" -%} {%- assign angoli = "-90,90" -%} {%- assign righe = 2 -%} {%- else -%} {%- assign angoli = "0" -%} {%- assign righe = 1 -%} {%- endif -%} {%- assign lista = angoli | split: "," -%} {%- assign per_riga = n | divided_by: righe -%}
